# admin-SK

Swayamkrushi Management Console & CMS Application

## Features
- Overview & Live IP Visitor Analytics
- Newsletter & Email Campaign Broadcasts
- Managing Committee & Governance Administration
- Media Buzz & Press Coverage Manager
- Articles & Stories CMS with Tiptap Rich-Text Editor & Video Streaming
- Insiders Video Stories Manager
- Accolades & Recognition Timeline
- Statutory Certificates & Media Uploads
- FAQs Manager
- Contact Messages & Inquiries
- Website Settings & Circular Cropper CMS

## Tech Stack
- React 18 + Vite
- Lucide React Icons
- Tiptap Rich Text Editor
- Production Cloud API: `https://api.swayamkrushi.org/api`
